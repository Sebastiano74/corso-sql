Spiegazione semplice:
ORDER BY serve per ordinare le righe del risultato in base a una o più colonne.

ASC = ascendente (dal più piccolo al più grande: A → Z, 1 → 100)

DESC = discendente (dal più grande al più piccolo: Z → A, 100 → 1)

Se non specifichi niente, il default è ASC.

Sintassi:
SELECT colonne FROM tabella
ORDER BY colonna1 [ASC|DESC], colonna2 [ASC|DESC];
